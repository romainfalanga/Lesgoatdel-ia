Une nouvelle approche pour maîtriser son environnement de travail numérique voit le jour, permettant de bloquer sélectivement les sites web distrayants comme les réseaux sociaux ou la messagerie électronique pendant les plages horaires dédiées à la concentration. L'objectif est de reprendre le contrôle sur les outils numériques et de s'assurer que seul le contenu pertinent accède à l'espace de travail.

## Création d'une extension personnalisée avec Claude Code

Le processus de création débute par l'utilisation d'un outil d'IA conversationnelle spécialisé dans le code, permettant de générer une extension Chrome sans écrire une seule ligne de code manuellement. L'utilisateur dicte ses instructions vocales, qui sont ensuite transformées en code fonctionnel. L'outil propose un mode automatique pour la génération de code et permet un choix du modèle d'IA à utiliser, ici le modèle Fable 5.1.

## Conception et validation de l'architecture

Avant de procéder à la génération du code, une étape de planification est essentielle. Un « mode plan » permet de valider l'architecture globale de l'extension et sa logique de fonctionnement. Ce plan est soumis à l'IA pour validation, assurant que la structure prévue correspond aux besoins avant que le code ne soit écrit. Un fichier `CLAUDE.md` est utilisé pour obliger l'IA à tester elle-même le code qu'elle produit, garantissant ainsi sa fiabilité.

## Installation et configuration de l'extension

Une fois le code généré et validé, l'extension peut être installée dans le navigateur Chrome via le mode développeur. Cette méthode permet d'installer des extensions non empaquetées directement depuis les fichiers sources. L'extension est ensuite configurée pour bloquer des sites spécifiques (tels que LinkedIn, Gmail ou X) pendant des plages horaires prédéfinies, par exemple entre 7h et midi.

## Mécanismes de résistance à la procrastination

Pour renforcer l'efficacité de l'outil, des garde-fous anti-triche sont intégrés. L'accès aux sites bloqués n'est pas immédiat ; il nécessite de passer par un arbre de questions destiné à évaluer la réelle nécessité de contourner le blocage. De plus, pour sortir du mode restreint, l'utilisateur doit recopier une phrase spécifique à la main, empêchant ainsi le copier-coller et décourageant les impulsions de procrastination. Les objectifs personnels sont affichés à la place des sites bloqués pour maintenir la motivation.

## L'avantage des outils internes

L'utilisation d'outils internes, créés sur mesure pour répondre à des besoins spécifiques, représente un gain de productivité significatif. Ces solutions personnalisées permettent une adaptation parfaite aux flux de travail individuels, contrairement aux outils génériques qui peuvent imposer des contraintes ou ne pas couvrir toutes les exigences. La capacité de dicter ses besoins et de voir l'outil prendre forme rapidement grâce à l'IA ouvre de nouvelles perspectives pour l'optimisation personnelle et professionnelle.

## À retenir

*   Planifier et valider l'architecture avant la génération du code.
*   Intégrer des mécanismes de blocage horaire et des garde-fous anti-triche.
*   La recopie manuelle d'une phrase est une barrière efficace contre la procrastination.
*   Les outils internes personnalisés offrent un avantage productif majeur.
